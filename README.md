# Student Workshop on Assured Autonomy for National Security

Event page for the CU Boulder and Front Range Consortium student workshop,
November 16-17, 2026.

Live at https://assured-autonomy-workshop.github.io/

The site is one self-contained file, `index.html`, with no build step and no
external assets. GitHub Pages serves it from the root of `main`; a push to
`main` republishes it within a minute or two.
